# Study Compass

Study Compass is a browser based study dashboard for planning exams, saving paper patterns, setting reminders, tracking preparation, and working through math problems step by step.

## Run it

Open `index.html` in a browser. No installation or account is needed. Exam data is saved locally in the browser you use.

## Project files

- `index.html` contains the page structure.
- `styles.css` contains the visual design and responsive layout.
- `app.js` contains the exam planner, reminders, focus timer, and math solver.
- `study-compass.html` is the original single-file version for easy downloading.

## Math solver

The solver handles arithmetic, one-variable linear equations, and systems of linear equations. Enter one equation per line for a system, for example:

```text
2x + y = 7
x - y = 1
```

It shows the variable order, augmented matrix, row operations, and final values.
